# Shopper

## 🛒 Shopper: Your One-Stop Shop for All Clothing Needs!

Shopper is a modern e-commerce platform that brings you an extensive range of clothing options for **kids, women, and men**. Built with **HTML, CSS, JavaScript, and React**, this app offers a seamless and engaging shopping experience.

---

### 🚀 Features

- **Clothing Categories**: 
  - Kids' Clothes
  - Women's Fashion
  - Men's Fashion
- **Authentication**:
  - Login and Logout functionality for secure shopping.
- **Product Details**:
  - High-quality images, detailed descriptions, and clear pricing.
  - **Discount Offers** with updated pricing.
- **Responsive Design**:
  - Optimized for desktops, tablets, and mobile devices.

### 🔧 Installation

Follow these steps to set up the project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/vishakha115/ecommerce-frontend-app
   ```

2. Navigate to the project directory:
   ```bash
   cd shopper
   ```

3. Install the dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open your browser and visit:
   ```
   http://localhost:3000
   ```

### Additional Notes

- Ensure **Node.js** is installed (version 14 or later).
- Run `npm audit fix` to resolve any dependency issues if necessary.
- If you face issues with the local server, try running:
  ```bash
  npm start
  ```
